Ask: which operation can combine information from channel 0 and channel 1?

One pointwise calculation

After depthwise filtering, a pixel has values [2, −1, 3]. Two output filters have weights [1, 0.5, −0.25] and [−0.5, 1, 0.5]. No bias or activation.

output 0 = 1·2 + 0.5·(−1) − 0.25·3 = 0.75 output 1 = −0.5·2 + 1·(−1) + 0.5·3 = −0.50

A 1×1 filter has spatial size 1×1 but spans all input channels.
